# Обзор проекта

## О проекте

**GeoCheck AI** — браузерное приложение (vanilla TypeScript + Vite) для верификации геометрических чертежей по текстовому условию. Пользователь загружает растровый чертёж, выбирает правило и погрешность ε; движок в браузере (OpenCV.js + Tesseract.js через WASM) строит граф чертежа и выносит вердикт.

Описывает инструмент из `product-brief.md` (ТЗ) / `context/project-brief.md` (адаптация). Школьный/портфолио проект: без сервера, без БД.

## Проблема, которую решает

Ручная проверка чертежей по геометрическим условиям — рутина для преподавателя. Пайплайн «линии → дедупликация → OCR → граф → верификация» автоматизирует её и возвращает **обоснованный вердикт с числом отклонения**.

## Поверхности

| Маршрут          | Что это                                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| `/` — один экран | зона загрузки (drag-and-drop), выбор правила, слайдер ε, холст с рендером распознанного, панель вердикта |

## Основные пользовательские сценарии

1. Загрузить чертёж (drag-and-drop или выбор файла) → превью на холсте.
2. Выбрать правило: перпендикулярность / параллельность / равенство отрезков / принадлежность точки.
3. Настроить ε слайдером (0.5–10, по умолчанию 3.0).
4. Запустить проверку → вердикт: `Success` / `Fail` с описанием отклонения / мягкая ошибка о ненайденной букве.
5. Увидеть на холсте распознанные отрезки и метки (трассировка пайплайна).

## Вне области (не строим)

- Сервер, база данных, авторизация, мультипользовательность
- Мобильные/нативные приложения; «тёмная тема» (одна светлая тема)
- Распознавание многословного/цифрового текста (только одиночные A–Z)
- Автоматический подбор порогов (30 px, 5°, 7 px, 40 px фиксированы ТЗ; настраивается только ε)

## Поставка (deliverables)

1. SPA (Vite + TS) с полным пайплайном и вердиктом по ТЗ.
2. Тесты (Vitest) на пайплайн, включая критерии приёмки из ТЗ §5.
3. `README.md` + локальный `git`-репозиторий (на GitHub — только финальная версия).
4. Дизайн-токены («Чертёжная доска») в `context/ui-tokens.md` / `DESIGN.md`.

## Критерии успеха

- Прямоугольный треугольник → `Success`; угол 84° при ε=3 → `Fail` с текстом из ТЗ; точка за концом отрезка → `Fail`.
- Ненайденная буква → мягкая ошибка, без падений.
- `pnpm test` + `pnpm typecheck` + `pnpm build` зелёные.
- Обработка изображения ≤ 3 с на CPU (проверяемо на демо-чертеже).
