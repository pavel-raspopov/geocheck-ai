# Продукт

## Платформа

web — браузерное SPA (без сервера и БД; всё исполняется в браузере через WASM).

## Стек

Vite + TypeScript (vanilla SPA) + OpenCV.js + Tesseract.js (WASM) + Vitest (TDD). Подтверждено в `context/architecture.md`. Статус билда — `context/progress-tracker.md`.

## Пользователи

Основной: преподаватель геометрии (или школьник на уроке), который загружает растровый чертёж и геометрическое условие и получает вердикт «Верно / Ошибка с описанием отклонения».
Вторичный: рецензент на защите проекта — решение должно читаться как аккуратная инженерная работа (тесты, README, честные формулировки).

## Назначение продукта

**GeoCheck AI** автоматически проверяет, соответствует ли растровый чертёж **условиям геометрической задачи**: пользователь вставляет текст задачи и чертёж → система извлекает из текста правила построения (оффлайн-парсер; Gemini — ручной фолбэк) → пользователь подтверждает правила → движок проверяет чертёж по всем подтверждённым правилам (детекция линий → дедупликация → OCR-метки → граф → мульти-верификация). Задача НЕ решается — проверяется только корректность построенного чертежа.

## Позиционирование

Школьный/портфолио проект: цель — точность ≥ 95% на «цифровых» чертежах и полное исключение ручной проверки графической части. Не коммерческий продукт, не стартап.

## Ключевые параметры (из ТЗ, ред. 2026-09-17)

- Min длина отрезка — 30 px; кластеризация — ≤ 5° и ≤ 7 px; привязка буквы — ≤ 40 px; ε по умолчанию — 3.0
- Accuracy ≥ 95% (требование «≤ 3 с» из ТЗ убрано)
- Мягкая ошибка: `[Status: Error] Точка X не найдена на чертеже`; фейл: `Ошибка: Угол на рисунке равен 84.12°, отклонение составляет 5.88°`
- Сценарии правил: градусная мера угла, параллельность, равенство отрезков, принадлежность точки, медиана, биссектриса, высота, перпендикуляр
- Абсолютные длины из текста («16 см») не верифицируются — показываются как «дано»

## Возможности и ограничения

**В области:** SPA с загрузкой файла (drag-and-drop), полем текста задачи и слайдером ε; область распознанных правил с подтверждением пользователя (human-in-the-loop); опциональная фолбэк-секция Gemini (API key вводит пользователь, максимум localStorage); холст с рендером чертежа и оверлеем; пайплайн CV/OCR/граф/правила/верификация; testdata-харнесс; тесты (TDD); README.

**Вне области:** сервер и БД, авторизация, дефолтный ключ в `.env` (решение 2026-09-17), мультипользовательность, мобильные/нативные приложения, «тёмная тема» (одна светлая тема «Чертёжная доска»), распознавание многословного текста (только одиночные A–Z), автоматический подбор порогов (30 px / 5° / 7 px / 40 px фиксированы ТЗ; настраивается только ε), решение задачи и вычисление неизвестных величин.

## Обязательства бренда

- Имя: **GeoCheck AI**
- Голос: точный, спокойный — «как у доски в классе»: понятный вердикт и понятное число отклонения.
- Визуальная система: `DESIGN.md` + `context/ui-tokens.md` («Чертёжная доска»: светлый фон, ink-синий акцент, табулярные цифры, hairline-границы).

## Принципы продукта

1. **Честный вердикт.** Успех / ошибка / граничный случай — только с обоснованием (числом отклонения).
2. **Мягкие отказы.** Ненайденная буква — понятное сообщение `[Status: Error] ...`, а не `KeyError`/падение.
3. **Параметры наружу.** Пороги — константы (`src/pipeline/constants.ts`), ε — настройка в UI; без магических чисел в логике.
4. **Простота стека.** Всё в браузере; один `pnpm build` = рабочий `dist/`.
