# Продукт

## Платформа

web — браузерное SPA (без сервера и БД; всё исполняется в браузере через WASM).

## Стек

Vite + TypeScript (vanilla SPA) + OpenCV.js + Tesseract.js (WASM) + Vitest (TDD). Подтверждено в `context/architecture.md`. Статус билда — `context/progress-tracker.md`.

## Пользователи

Основной: преподаватель геометрии (или школьник на уроке), который загружает растровый чертёж и геометрическое условие и получает вердикт «Верно / Ошибка с описанием отклонения».
Вторичный: рецензент на защите проекта — решение должно читаться как аккуратная инженерная работа (тесты, README, честные формулировки).

## Назначение продукта

**GeoCheck AI** автоматически проверяет, соответствует ли растровый чертёж текстовому геометрическому условию: детекция линий → дедупликация → OCR-метки → сборка графа → верификация инвариантов. Успех: загрузил чертёж, выбрал правило (перпендикулярность / параллельность / равенство отрезков / принадлежность точки), подвинул ползунок погрешности — и получил обоснованный вердикт за ≤ 3 секунды на CPU.

## Позиционирование

Школьный/портфолио проект: цель — точность ≥ 95% на «цифровых» чертежах и полное исключение ручной проверки графической части. Не коммерческий продукт, не стартап.

## Ключевые параметры (из ТЗ)

- Min длина отрезка — 30 px; кластеризация — ≤ 5° и ≤ 7 px; привязка буквы — ≤ 40 px; ε по умолчанию — 3.0
- Accuracy ≥ 95%; обработка одного изображения ≤ 3 с на CPU
- Мягкая ошибка: `[Status: Error] Точка X не найдена на чертеже`

## Возможности и ограничения

**В области:** SPA с загрузкой файла (drag-and-drop), выпадающим списком правил и слайдером ε; холст с рендером чертежа и оверлеем распознанного; пайплайн CV/OCR/граф/верификация; тесты (TDD); README.

**Вне области:** сервер и БД, авторизация, мультипользовательность, мобильные/нативные приложения, «тёмная тема» (одна светлая тема «Чертёжная доска»), распознавание многословного текста (только одиночные A–Z), автоматический подбор порогов (30 px / 5° / 7 px / 40 px фиксированы ТЗ; настраивается только ε).

## Обязательства бренда

- Имя: **GeoCheck AI**
- Голос: точный, спокойный — «как у доски в классе»: понятный вердикт и понятное число отклонения.
- Визуальная система: `DESIGN.md` + `context/ui-tokens.md` («Чертёжная доска»: светлый фон, ink-синий акцент, табулярные цифры, hairline-границы).

## Принципы продукта

1. **Честный вердикт.** Успех / ошибка / граничный случай — только с обоснованием (числом отклонения).
2. **Мягкие отказы.** Ненайденная буква — понятное сообщение `[Status: Error] ...`, а не `KeyError`/падение.
3. **Параметры наружу.** Пороги — константы (`src/pipeline/constants.ts`), ε — настройка в UI; без магических чисел в логике.
4. **Простота стека.** Всё в браузере; один `pnpm build` = рабочий `dist/`.
